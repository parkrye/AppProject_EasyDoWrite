# EasyDoWrite

인터넷 권한 없는 안드로이드 연재 소설 집필 앱. 원고(화 · 부 · 외전), 설정 위키, 아이디어 메모, 글자 수 목표를 한 앱에서 관리하고, 데이터는 기기 밖으로 나가지 않음.

## 기능

| 영역 | 내용 |
|---|---|
| 작품 | 상태 · 소개 · 목표 글자 수(작품 · 화당 · 하루) · 날짜별 작성 기록 |
| 원고 | 부 · 외전 묶음, 화 유형(프롤로그 · 본편 · 에필로그 · 후기 · 공지), 묶음별 화수 자동 · 직접 지정, 끌어서 정렬, 자동 저장, 이전 판 |
| 주석 | 화 메모 · 본문 구간 각주. 원고 텍스트에는 섞이지 않음 |
| 위키 | 인물 · 설정 · 사건 · 물건 · 장소 · 세력 · 용어, `[[문서]]` 링크 · 역링크, 이미지, 메모 · 각주, 연표, 여러 작품이 공유하는 세계관 |
| 메모 | 태그 · 고정 · 작품 지정, 위키 문서 · 새 화로 옮기기 |
| 읽기 | 연속 스크롤 · 쪽 넘김, 글꼴 · 크기 · 줄 간격 · 배경, 이어 읽기 |
| 기타 | 작품 안 검색 · 원고 모두 바꾸기, 휴지통(30일), zip 백업 · 복원, txt 내보내기 |

글자 수는 기본 공백 제외, 설정에서 공백 포함으로 바꿀 수 있음.

## 설치

[Releases](../../releases)에서 `EasyDoWrite-<버전>.apk`를 받아 설치. Android 8.0 이상.

- 처음 설치 시 "출처를 알 수 없는 앱" 설치 허용 필요. Play 프로텍트가 검사 화면을 띄울 수 있음
- 업데이트는 새 APK를 같은 방식으로 덮어 설치. 원고 · 설정 유지
- 앱 안 업데이트 알림 없음. Releases 페이지에서 직접 확인
- 서명 인증서 SHA-256: `361872d81583c7f72c743d20ca6bb6e3c8705d442194282a421ba2499d3f08b6`
  (`apksigner verify --print-certs EasyDoWrite-<버전>.apk`로 확인)

## 개인정보

- **인터넷 권한 없음.** 수집 · 전송하는 데이터 없음. 계정 · 광고 · 사용 통계 · 오류 보고 없음
- 원고 · 위키 · 메모 · 이미지는 기기 안에만 저장. 앱 삭제 시 함께 삭제 (Android 클라우드 백업도 끔)
- 앱 안 백업 파일 · txt는 사용자가 고른 위치에만 저장. 기기를 바꿀 때는 백업 파일을 옮겨 복원
